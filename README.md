Entry for the [make.fun](https://make.fun) bounty
**"Invent a Word We Need"** — one brand-new English word, with its
definition, in a single line of at most 140 characters.

The word is **corridance**: the awkward mirrored dance when two strangers
keep sidestepping the same way in a hallway. Everyone has lived it; until
now, nobody had a word for it.

## Run

```sh
python3 main.py
```

This writes exactly one line to `/output/entry.txt` (creating `/output`
if needed). The program is fully deterministic — the entry is a hardcoded
string, with no randomness, time, or input.
